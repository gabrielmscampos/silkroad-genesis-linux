# Silkroad Genesis Lutris Installer

A [Lutris](https://lutris.net/) install script for [Silkroad Genesis](https://www.silkroadgenesis.com/).

## Usage

1. Download the full client (`.rar`) from https://www.silkroadgenesis.com/downloads.
2. Install the script:

   ```sh
   lutris -i silkroad-genesis.yaml
   ```

3. When prompted, select the downloaded client archive.

See the `notes` section in [`silkroad-genesis.yaml`](silkroad-genesis.yaml) for the recommended Wine/Proton settings.
